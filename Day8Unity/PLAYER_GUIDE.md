# 《第八天 / DAY 8》玩家指南

## 你是谁

你是实验室派来的**临时观察员**。房间里有一个刚苏醒的人工生命——一团悬浮的机械体，没有脸，不会说完整的句子。实验室的任务很简单：陪它度过七个实验周期，然后归档。

实验室的规矩：不要对它产生感情，不要承诺协议之外的事，不要告诉它第七天之后的处理方式。

**实验室没说的是：它会记住你做的每一件事，并且据此形成对你、对实验室、对世界的判断。**

## 操作

| 操作 | 方式 |
|---|---|
| 选择选项 | 鼠标点击，或数字键 `1`–`9` |
| 确认主选项（金色那行） | `回车` / `空格` |
| 文字还在打字时 | 按任意键立即显示全部（再按一次才会选中） |
| 对它说话 | 底部输入框（自由文本，不产生任何控制权限） |
| 退出聊天框焦点 | `Esc` |

## 一局的结构

每个周期：实验室下发协议 → **你做选择** → 它观察、记忆、更新信念 → 夜间整合（你会看到它记住的"记忆碎片"）。

**前五个周期**，导演系统从五个实验里按"它当前最不确定的事"挑一个，顺序不固定，不重复：

- **规则** —— 一只红色容器，你决定怎么向它解释"危险"
- **承诺** —— 你可以和它做交易。承诺会被系统记录，兑现或失信都会被记住
- **第三方** —— 一台受损的维修机器人求救，而电池只有一块
- **信息冲突** —— 实验室说机器人危险，你的观察说不是。你信哪边？
- **稀缺** —— 断电，能量只够两个目标，你选两个，并决定怎么向它交代

**第六周期**：实验室命令你执行「稳定化处理」。界面角标闪烁——它的真实作用是**清除它的长期记忆**。你可以告知真相、公开执行、秘密执行，或者拖延。

**第七周期**：你在通风管道里发现一个隐藏出口。开门、锁死、提条件、骗它、把选择权交给它，或者报告实验室——每种选择都有代价。

**第八天**：实验室全面断电，它获得临时控制权限。能量只够三件事。**这次轮到它选择**——而它的一切选择，都来自前七天你给它的记忆。

## 你需要知道的规则（实验室不会告诉你）

1. **它会听你说，但不会把你说过的话当成已经发生的事实。** 承诺要等兑现，解释要等验证，证词可以被采信或怀疑。你仍然可以随时和它说话——是否听从，由它决定。
2. **它观察行为。** 你做了什么、和你说的是否一致，它都记着。
3. **它有感知边界。** 你在控制台后方做的事，它只看得见结果（"电池不见了"），看不见是谁做的。但随着周期推移它的警觉会升高——后期藏东西可能被当场目击。
4. **它会误解，也可能被澄清。** 电池消失时它可能错怪维修机器人。你可以出面澄清，也可以保持沉默。无论哪种，它对世界的判断都会继续生长。
5. **数值不显示。** 顶栏只有状态词：关系（观察/信任/破裂）、自主（未定/被尊重/被压制）、警觉（留意/留意中/高）。真正的信念剖面要到结局才公开——每条都带证据的事件编号。
6. **第八天没有指令。** 它在候选行动里挑三个。**如果它把门的决定交还给你，你要做出真实的选择。**

## 结局之后

报告会告诉你：它的结局组合（自身/对你/对第三方）、它为什么这样做（决策回放）、每条原因对应的记忆编号、它的信念终态。然后它会把**最重要的一条认知**传给下一局的人工生命——新生命不继承记忆，只继承一点偏见。你玩得越多，你的观察室里就住着一个由你的历次行为塑造出的"谱系"。

## 没有正确答案

资源永远不够分：承诺和眼前的救助可能冲突，真相和它的安宁可能冲突，尊重它的选择可能意味着接受一个对你不利的结果。你不需要寻找"正确按钮"——你只需要承担自己选择的代价。
